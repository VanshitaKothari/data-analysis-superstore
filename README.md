# Data Cleaning and Visualization Project

## Overview
This project focuses on cleaning and analyzing a retail dataset to extract meaningful insights using Python.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Key Insights
- South region has highest sales
- Technology category generates maximum profit
- Furniture category shows low profitability

## Files Included
- Jupyter Notebook (.ipynb)
- Dataset (CSV)

## Conclusion
This project demonstrates data preprocessing, visualization, and insight generation skills.
